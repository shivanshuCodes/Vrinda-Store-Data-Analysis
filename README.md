# Vrinda-Store-Data-Analysis 
📌 Project Overview
This project analyzes Vrinda Store’s 2022 sales data using Microsoft Excel to generate business insights through an interactive dashboard.

🎯 Objective
To analyze:
Monthly sales trends
Sales distribution by gender
Order status performance
Top-performing states
Sales contribution by channel

🛠 Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning Techniques

📊 Key Insights
Women contribute 64% of total sales
92% of orders are delivered
Amazon has the highest order share
Maharashtra generates highest revenue


->Final Conclusion to improve Vrinda store sales:
Target women customers of age group (30–49 yrs) living in Maharashtra, Karnataka and Uttar Pradesh by showing ads/offers/coupons available on Amazon, Flipkart and Myntra.
